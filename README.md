# Railway Ticket Booking System (C++)

## Project Description
The Railway Ticket Booking System is a menu-driven C++ project that allows users to book, view, search, and cancel railway tickets.

## Features
- Display available trains
- Book railway tickets
- View all bookings
- Search tickets using PNR number
- Cancel booked tickets
- Check available seats

## Technologies Used
- Programming Language: C++
- Concepts: Classes, Objects, Constructors, Vectors, Functions, Encapsulation

## How to Run
1. Download the `RailwayBooking.cpp` file.
2. Open it in a C++ compiler.
3. Compile and run the program.
